# Gate Contract

This is the platform's acceptance contract for the promoted repo. Each row is one gate: its id, the component that owns it, the check that evaluates it, the pass criterion, and its status. Each id appears once, under its owner. A blank status means the gate is defined and no result is claimed here. LIVE-POSSIBLE is the research's venue status: the gate can run on free local infrastructure, and no result is claimed. An OPEN status means the gate cannot be evaluated yet and stays open until its stated condition is met. This file defines gates; it does not claim results.
